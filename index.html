Exam Timetabling Engine

2026

FEUP’s exam calendar, generated by a solver

The university’s exam-scheduling rules written as a mixed-integer program in IBM ILOG CPLEX, run on real enrolment data for the whole Informatics Engineering programme.

  • Built the capstone’s Python pipeline: it scrapes real enrolment data, feeds the CPLEX model and writes the timetable back to Excel.
  • After the capstone, rebuilt it on my own: one model instead of nine copies, and an independent checker that re-verifies every rule.
  • Fixed three bugs in the model, each pinned by a regression test. An infeasible input now names the rules in conflict.
  • Python
  • IBM ILOG CPLEX
  • OPL
  • Mixed-integer programming

Rotina

2026

Gym, running and nutrition plans generated for each person

A multi-user app for training, running, food and calendar. A short onboarding turns what each person enters into their own routine, running plan and calorie target.

  • Offline-safe set logging: every set carries a client-generated id, so a retried request never duplicates a set or erases a personal record.
  • An adaptive nutrition engine that tells “no data” apart from “low adherence”, and never cuts calories without reliable data.
  • A 17-week running plan generated by rule: 10% weekly increases, a deload every fourth week, long runs capped at half the volume.

Spotiganizer

2026

Collections, tags and smart playlists on top of Spotify

Organises a Spotify library more freely than the app allows, with a small dashboard of what you’ve been listening to.

  • Collections and tags for saved tracks — groupings the Spotify API doesn’t expose — plus rule-based smart collections.
  • Exporting a collection keeps one private playlist in sync, instead of creating a duplicate on every export.
  • OAuth with PKCE through Auth.js; the refresh token is encrypted at rest with AES-256-GCM.

Open source · kubernetes/kubernetes #141622

In review

A fix for a crash that could take down kube-controller-manager

I picked up an open bug report in Kubernetes’ node lifecycle controller. When a cluster leaves disruption mode — typically while it recovers from a large outage — a node with no recorded health data made the controller dereference a nil entry and take the whole process down. The fix has two parts, and a regression test that reproduces the crash against the old code.
