Rotina

An app to run four things at once: gym, running, food and calendar. Multi-user — each person gets a short onboarding and leaves with their own training routine, running plan and nutrition target, generated from what they entered rather than a generic template.

  • Offline-safe set logging: every set carries a client-generated id, so a lost network response is retried without duplicating the set or breaking a personal record.
  • An adaptive nutrition engine that tells “no data” apart from “low adherence” and reacts differently to each — it never cuts calories without reliable data, but raises them on early signs of losing too fast.
  • A 17-week running plan generated by rule (10% weekly volume increase, a deload every four weeks, long run capped at 50% of volume), not written by hand.
